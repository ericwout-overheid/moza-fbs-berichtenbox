# Beveiligingsbeleid / Security Policy

## NL: Coordinated Vulnerability Disclosure

Wij nemen de beveiliging van dit project serieus. Als je een beveiligingsprobleem
hebt gevonden, waarderen we je hulp bij het verantwoord melden ervan.

### Ondersteunde versies

| Versie | Ondersteund |
|--------|-------------|
| latest (main) | Ja |
| Oudere versies | Nee |

### Een kwetsbaarheid melden

**Meld beveiligingsproblemen NIET via openbare GitHub issues.**

Stuur in plaats daarvan een e-mail naar: **security@example.nl**

Vermeld in je melding:

- Een beschrijving van de kwetsbaarheid
- Stappen om het probleem te reproduceren
- Mogelijke impact
- Eventuele suggesties voor een oplossing

### Wat kun je verwachten?

- **Binnen 3 werkdagen**: Bevestiging van ontvangst van je melding
- **Binnen 10 werkdagen**: Eerste beoordeling en terugkoppeling
- **Doorlopend**: We houden je op de hoogte van de voortgang

Wij vragen je om:

- De kwetsbaarheid niet openbaar te maken totdat er een oplossing beschikbaar is
- Geen misbruik te maken van de kwetsbaarheid
- Voldoende informatie te geven zodat wij het probleem kunnen reproduceren

## EN: Coordinated Vulnerability Disclosure

We take the security of this project seriously. If you have found a security
vulnerability, we appreciate your help in disclosing it responsibly.

### Supported Versions

| Version | Supported |
|---------|-----------|
| latest (main) | Yes |
| Older versions | No |

### Reporting a Vulnerability

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, send an email to: **security@example.nl**

Please include in your report:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggestions for a fix

### What to Expect

- **Within 3 business days**: Acknowledgment of your report
- **Within 10 business days**: Initial assessment and feedback
- **Ongoing**: We will keep you informed of progress

We ask that you:

- Do not disclose the vulnerability publicly until a fix is available
- Do not exploit the vulnerability
- Provide sufficient information for us to reproduce the issue
